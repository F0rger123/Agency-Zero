# Ranking for "Agency Zero" (brand search)

"Agency Zero" is a generic phrase, so other businesses and pages can compete for it. Google decides who shows first; nobody can force
position 1, but these things reliably help. New sites typically need **2-8 weeks** after indexing before a brand search is reliable.

## Built into the site (done)
- Home `<title>` starts with the brand: "Agency Zero | Web Design, Custom Software & SEO in York, PA"; the `<h1>` is "Agency Zero"; the meta description opens with "Agency Zero is a York, PA ...".
- Structured data: `name`, `alternateName` (Agency Zer0, AgencyZero, theagencyzero.com, Agency Zero York PA), a `disambiguatingDescription`, PNG logo (512px, which Google prefers over SVG),
  `sameAs` (Instagram, plus the Google Business Profile once `NEXT_PUBLIC_GBP_URL` is set), and `WebSite` name/alternate name so the site name appears correctly in results.
- Favicons: SVG + 192px PNG + Apple icon, so the icon appears next to the result.
- Footer and `llms.txt` state the full identity on every page (name, York PA, domain, owner).

## You do (this is what moves a brand search)
1. **Google Search Console**: verify, submit the sitemap, request indexing of `/`, `/about`, `/contact`, `/services` and each service page.
2. **Google Business Profile**: name exactly `Agency Zero`, website `https://theagencyzero.com`. When verified it often takes the right-hand knowledge panel for brand searches.
3. **Claim the same name + same link everywhere** (these show up on page 1 for brand searches and tell Google they are the same entity):
   Instagram (@agency.zer0: set the bio link to https://theagencyzero.com and the bio to "York, PA marketing & web agency"),
   Facebook page, LinkedIn company page, YouTube channel, TikTok, X, Pinterest, Bing Places, Apple Business Connect, Yelp,
   Nextdoor, Clutch, DesignRush, Crunchbase, and the local chamber of commerce.
4. **Use one description and one name spelling** ("Agency Zero", not "AgencyZero" or "Agency Zer0" in your own copy). The "0" wordmark is a design choice; the plain-text name is Agency Zero.
5. **Get linked**: every client site gets a footer link "Website by Agency Zero" to https://theagencyzero.com; ask friendly local businesses to list you.
6. **Search "Agency Zero York PA"** too and tell people to: that longer phrase is much easier to win than the bare name, and it is what the profile and titles target.
7. Check Search Console > Performance, filter by query containing "agency zero": it shows your real impressions and position.
